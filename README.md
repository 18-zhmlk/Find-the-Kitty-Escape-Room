# 🐈 Find the Kitty

**Find the Kitty** is a horror puzzle game developed in Roblox Studio. Explore a mysterious house, solve puzzles, discover hidden clues, face terrifying creatures, and find your way to Loki.

## 🎮 About the Game

You find yourself in a mysterious house where nothing is quite as it seems. To complete your journey, you must explore different areas, collect clues, solve puzzles, and uncover the secrets hidden inside.

Your ultimate goal is to survive and rescue Loki.

## ✨ Features

- **Horror Atmosphere** — dark environments, creepy sounds, and unexpected scares.
- **Exploration** — discover hidden objects, notes, and secrets throughout the house.
- **Puzzles** — solve challenges using clues and environmental interactions.
- **Interactive Gameplay** — interact with objects, read notes, light candles, and unlock doors.
- **Monster Encounter** — face a dangerous monster and fight to survive.
- **Final Ending** — complete your journey and rescue Loki.

## 🧩 Gameplay

Throughout the game, players will need to:

1. Explore the house and collect hidden clues.
2. Solve puzzles to unlock new areas.
3. Find and read mysterious notes.
4. Complete interactive challenges.
5. Confront the monster.
6. Reach Loki and complete the game.

## 🛠️ Built With

- **Roblox Studio** — game development environment.
- **Luau** — scripting language.
- **Roblox Engine** — game physics, interactions, and gameplay systems.

## 📁 Project Structure

The project is developed in Roblox Studio and includes:

- Game environment and 3D models
- Lua/Luau scripts
- Interactive objects and puzzle systems

- User interface and gameplay elements
